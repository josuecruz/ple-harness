## Method (for reproducibility)

The entry is the reference tool-calling harness (WebSocket protocol via
`taskbridge.py`) with one change: a system-prompt checklist that requires the
model to (a) locate values, callouts and code clauses in the project files,
(b) keep units attached and maintain a calculation ledger, and (c) reopen and
validate each deliverable before sending `done`. `ENGINEERING_MODE=0` disables
the checklist for the ablation. The harness runs with a per-task deadline,
context compaction, retry/backoff, and the task's MCP tools; all file and
command access goes through the evaluator protocol.
